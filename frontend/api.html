API Documentation

Explore the UsageMeter API endpoints and learn how to use them.

Health & Status

GET /health

Check whether the API service is running.

GET /health/db

Check the API's database connection status.

Plans & Usage

GET /plans

Retrieve predefined plans. Supplying a valid API key also includes plans created for that account.

GET /usage/history

Retrieve paginated usage records for the account associated with the API key. Requires the X-API-Key header.

Authentication: Endpoints that require an API key expect it in the X-API-Key request header. Keep API keys private and never place real keys in public frontend code.
